## Magic references

- [Modern Masters (2015 Edition) Release Notes](https://magic.wizards.com/en/news/feature/modern-masters-2015-edition-release-notes-2015-05-12): persist returns a permanent from the graveyard if it had no -1/-1 counter, then places one on it.
- [Shadowmoor than Meets The Eye, Part III](https://magic.wizards.com/en/news/making-magic/shadowmoor-meets-eye-part-iii-2008-04-14): the mechanic was designed as saving a creature from death, with the -1/-1 counter marking that it had already been saved once.

The artwork depicts that single weakened return through a revenant gauntlet, one curse-gem and a rekindled spirit flame, without reproducing a card illustration or character.
